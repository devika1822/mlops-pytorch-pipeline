# MLOps PyTorch Pipeline

Individual assignment for deploying a PyTorch image classification workload using Docker and Kubernetes.

## Project Overview

This project demonstrates an end-to-end MLOps workflow for a PyTorch image classification model, including:

- PyTorch model training
- Dockerized training and inference
- Kubernetes training jobs
- Kubernetes model serving
- Configuration management
- Health checks and autoscaling

Detailed setup and execution instructions will be added as the project is developed.
